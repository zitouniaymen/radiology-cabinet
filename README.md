# radiology-ui

Frontend Angular 20 (composants standalone + Angular Material) du cabinet de radiologie.

```bash
npm install
npm start        # http://localhost:4200, proxy /api -> http://localhost:8080
npm run build    # build de production
npm run test:ci  # tests Karma/Jasmine en Chrome headless
```

Voir le [README racine](../README.md) pour le lancement complet (Docker Compose, API, base).
